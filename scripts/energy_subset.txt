#   - 每行一个**文件名**（不含目录），相对于 --source 指定的语料根目录；

#      冲突/差异对比，也便于构造黄金集；
#   2. **全部为文本型 PDF（有文本层，无需 OCR）**：逐一检查过 /Font 与 /Image 标记，
#      解析快、无扫描件，适配 16GB 单机演示环境；

#      （如 0006 绿色电力证书发展报告 100MB、0042 核电发展报告 5.5MB、
#      0100 电力市场发展报告 3.0MB）——它们解析慢且非首批必需；
#   4. **已排除重复文件**：0039 与 0040 内容**完全相同（md5 一致：8e4ffdfd…）**，
#      仅文件名不同，只保留 0039；重复入库会在检索结果里产生同源冗余证据；
#   5. 保留 1 份表格文件（0030 贵州电网销售电价表.xlsx），用于验证 RAGFlow 的
#      多格式解析链路（表格 → 结构化文本），避免只测 PDF 单一路径；
#   6. 语料本身**不入库**（NO-17），本清单只记录文件名，不复制文件内容。
